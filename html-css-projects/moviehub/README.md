# MovieHub – Movie Booking Portal 🎬

A beginner-level HTML project created to practise hyperlinks and webpage navigation through a movie booking portal concept.

## 🛠️ Technology Used
- HTML5

## 💻 Concepts Practised
- Basic HTML document structure
- Anchor (`<a>`) tags
- Hyperlinks and navigation
- Linking webpages
- Connecting different sections or pages
- Basic webpage organisation

## 🎯 Learning Objective
To understand how hyperlinks work in HTML and how they can be used to connect webpages and create simple navigation between different sections of a website.

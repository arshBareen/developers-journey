# HTML Tables

A beginner-level HTML assignment focused on creating and organising data using HTML tables.

## 🛠️ Technology Used
- HTML5

## 💻 Concepts Practised

- HTML table structure
- Table rows, headings and data cells
- Table borders, cellspacing and cellpadding
- Table alignment
- Caption element
- Rowspan and Colspan
- Nested tables

## 🎯 Learning Objective

To understand how HTML tables organise information into rows and columns and how table attributes can be used to structure complex layouts.

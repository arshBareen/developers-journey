# Cosmic Explorer – Space Encyclopedia 🚀

A beginner-level HTML project based on space exploration, created to practise HTML elements and webpage structure.

## 📚 Project Overview

This project presents space-related information through a simple webpage using HTML elements.

## 🛠️ Technology Used
- HTML5

## 💻 Concepts Practised
- HTML document structure
- `<div>` elements
- Anchor (`<a>`) tags and hyperlinks
- Image (`<img>`) tags
- Basic webpage organisation and navigation

## 🎯 Learning Objective

To understand how HTML elements work together to organise content, display images and create navigation between webpages.

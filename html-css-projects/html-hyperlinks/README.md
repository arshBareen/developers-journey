# HTML Hyperlinks

A beginner-level HTML assignment focused on creating hyperlinks and navigating between multiple webpages.

## Tasks Covered

### Task 1 – Basic Hyperlinks
Created a webpage containing links to Google, Microsoft Bing and NareshIT.

### Task 2 – Multi-page Navigation
Created interconnected webpages using hyperlinks, including:
- Home Page
- About Us Page
- Image Details Page

Also practised making an image clickable to navigate to another webpage.

## Technology
- HTML5

## Concepts Practised
- Anchor (`<a>`) tags
- Hyperlinks and page navigation
- Linking multiple HTML documents
- Clickable images
- Relative file paths

# COLORVERSE – Emotional Color Gallery 🎨

A beginner-level HTML and CSS project exploring different colours, their formats and the emotions associated with them.

## 🛠️ Technology Used
- HTML5
- CSS3

## 💻 Concepts Practised
- HTML document structure
- CSS colour properties
- Different CSS colour formats
- Background colours
- Text styling
- Basic webpage layout and organisation

## 🎯 Learning Objective
To understand how different colour formats work in CSS and how colours can be used to create visually appealing webpage designs.
